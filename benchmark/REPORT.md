# Benchmark reports

Calibration evidence for the repository health score. One file per repository, each
generated by the benchmark harness and reproducible with the command printed at the top
of that file.

## Why there is more than one repository

`HALF_SCORE_DENSITY` was originally set from a single run, and it was far too lenient:
at density 100 every repository measured here scored between 87 and 92, including one
with four high-severity credential findings. One run cannot show where a curve should
bend — you need to see where real repositories actually cluster.

The worst-pillar density (weighted finding-points per KLOC) across five measurable
repositories lands in a tight band of **22–39**:

| Repository | LOC | Findings | Worst-pillar density |
| --- | --- | --- | --- |
| `krtk06/Chaty` | 2,565 | 13 | 31.2 |
| `psf/requests` | 12,032 | 63 | 22.9 |
| `pallets/click` | 30,181 | 164 | 33.8 |
| `pallets/flask` | 18,352 | 163 | 38.7 |
| `encode/httpx` | 17,753 | 157 | 38.6 |

Overall score under each candidate calibration (worst-pillar headroom held at 15):

| `HALF_SCORE_DENSITY` | Chaty | requests | click | flask | httpx | median |
| --- | --- | --- | --- | --- | --- | --- |
| 25 | 59 | 67 | 58 | 54 | 54 | 58 |
| **30 (shipped)** | **64** | **72** | **62** | **59** | **59** | **62** |
| 35 | 68 | 75 | 66 | 62 | 63 | 66 |
| 50 | 77 | 84 | 75 | 71 | 71 | 75 |
| 100 (previous) | 88 | 92 | 90 | 87 | 87 | 88 |

30 puts the median repository's weakest dimension near half marks and the overall in the
high fifties to low seventies. It was chosen from this table rather than tuned to make
any one repository look good.

## `octocat/Hello-World` and the missing denominator

This repository indexes to zero symbols, so `loc = 0` and density cannot be computed.
Under the old `MIN_KLOC = 0.001` floor the density became ~20,000 and two trivial
findings ("no test suite", "no README") scored the repository **15/100** — harsher than
a real repository with four high-severity credential findings. Both numbers were
artefacts of the denominator.

A missing LOC now switches the curve to raw weighted finding-points
(`COUNT_HALF_SCORE_PENALTY = 20`) and the payload records `basis: "count"`, so the number
is never silently compared against a density-scored one. Hello-World scores **65**.

## Reproducing

```bash
cd backend
python -m app.benchmark --analysis-id <id> --out ../benchmark/reports/<name>.md
```

The analysis IDs above refer to a local database. To rebuild them, register the
repository and start an analysis:

```bash
curl -X POST localhost:8000/api/repos -d '{"url":"https://github.com/pallets/click"}'
curl -X POST localhost:8000/api/repos/<repo_id>/analyze
```
